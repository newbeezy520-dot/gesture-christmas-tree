# Gesture Christmas Tree

手势控制的粒子圣诞树：用捏合打开相册，张掌让粒子飞散，收拢手掌让树重组。相册支持按钮、触屏滑动和左右挥手；两只手合成爱心并保持片刻，会点亮百日成就。背景音乐由 Web Audio 实时合成，可手动开启或关闭。

这个公开代码版本只包含 **5 张几何 SVG 示例插画**，没有私人照片、录音、二维码、原网页地址或原项目的 Git 历史。

## 本地运行

需要 Node.js 20 或更新版本。项目没有运行时 npm 依赖。

```sh
npm run setup
npm start
```

打开终端显示的本地地址。首次 setup 会下载固定版本的 MediaPipe 运行库和手部模型，并逐个验证 SHA-256；下载结果位于被 Git 忽略的 `dist/vendor/`。此后网页只从自己的服务器读取这些资源。

不运行 setup 也可以使用按钮体验动画、相册、音乐和成就；摄像头识别需要先准备模型。

## 玩法

| 操作 | 效果 |
| --- | --- |
| 捏合拇指与食指 | 展开相册和法语圣诞祝福 |
| 张掌并移动 | 粒子跟随手掌飞散 |
| 自然收拢或握拳 | 重组成圣诞树 |
| 一只张掌向左 / 向右挥动 | 下一张 / 上一张，挥动后稍停再挥 |
| 两只手合成一颗心，保持约 1 秒 | 显示百日成就 |
| 右上角音乐按钮 | 手动开启或关闭背景音乐 |

双手爱心识别几何手势，不判断两只手是否属于不同的人。触屏按钮可预览全部效果；音乐默认关闭。

## 手机和部署

将运行过 setup 的 **`dist/` 目录**部署到支持 HTTPS 的静态网站托管服务。手机通过 HTTPS 打开并允许摄像头即可识别；localhost 适合电脑本地开发，手机访问电脑的普通 HTTP 局域网地址通常无法使用摄像头。微信内置浏览器受限时，可在系统浏览器中打开。

资源使用相对路径，可部署到网站根目录或 GitHub Pages 的项目子路径。自托管时参考 `dist/_headers` 设置响应头。此仓库的 GitHub 地址和个人现有网站相互独立。

## 替换为自己的照片

示例相册写在 `dist/index.html` 的 `.album` 区域。仅在自己的本地副本中创建 `dist/private-photos/`，将照片放入，再修改 `<img>` 的路径、图注和替代文本。相册张数由程序自动统计；修改增删数量时同步调整初始 `photoCounter` 文本。

`.gitignore` 已忽略 `private-photos/`、常见照片和音视频格式、截图、文档及打包文件。请勿用 `git add -f` 强制加入这些内容；也不要把真实照片转成 base64 或嵌入 SVG。若需要部署个人照片，请使用自己控制访问权限的托管方案。

## 验证

```sh
npm run check
npm test
```

check 会检查准备提交的文件是否含图片、嵌入照片、私人路径或符号链接，并检查 JavaScript 语法。单元测试使用纯合成坐标，无真人图像。

可选浏览器检查：

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
# 另开一个终端运行 npm start，然后执行：
npm run test:browser
```

也可通过 `CHROME_PATH` 指定已安装的 Chromium。测试使用虚拟摄像头和合成坐标，不会请求真实摄像头；截图仅写入被忽略的 `test-results/`。

## 文件和隐私

- `dist/`：静态网页、粒子动画、手势识别、合成音乐和示例插画。
- `scripts/`：本地服务器、公开依赖下载与源码检查。
- `tests/`：手势、音乐及浏览器交互验证。

摄像头画面仅在浏览器内处理，不录制、不上传。网页没有分析统计或服务端 API；内容安全策略将模型与资源请求限制在本站。音乐无需音频文件。MediaPipe 代码和模型为第三方公开资源，许可证见 `dist/vendor/LICENSE-MEDIAPIPE.txt`；下载清单和校验值见 `scripts/vendor-assets.json`。
